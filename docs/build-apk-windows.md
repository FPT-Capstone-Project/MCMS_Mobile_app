# Build APK locally on Windows

Run in the mobile project directory:

```powershell
npm run build:apk
```

The script uses Java from `JAVA_HOME` or Android Studio (`D:\Android studio\jbr` on this machine), and Android SDK from `ANDROID_HOME`, `ANDROID_SDK_ROOT`, or `%LOCALAPPDATA%\Android\Sdk`. No Expo account or cloud upload is needed.

The first build downloads Gradle and the required Android components. Keep an internet connection available. Subsequent builds reuse downloaded dependencies.

Output: `dist\apk\SmartMush.apk`. This is a signed release APK containing the JavaScript bundle; Expo Go and Metro are not required. Default architectures: `arm64-v8a,armeabi-v7a,x86_64` for physical Android phones and 64-bit Android emulators such as MuMu. To build a smaller APK for phones only:

```powershell
npm run build:apk -- -Architectures "arm64-v8a,armeabi-v7a"
```

API settings come from `.env`. Use a backend URL accessible from the phone. `EXPO_PUBLIC_APP_ENV` defaults to `staging` for this build. Public environment variables are embedded at build time: rebuild the APK after changing them.

The app ID is `com.smartmush.mcms`. Increment `expo.android.versionCode` in `app.json` for subsequent distributed releases.

The signing key lives in `.local-build\mcms-release.jks`. Its password is encrypted with Windows DPAPI in `.local-build\signing-password.xml`, usable only by the same Windows user on the same computer. Preserve both files for future APK updates. Do not commit them. Moving the key to another computer requires securely exporting its password from the original Windows account first.

Native Android files are generated by Expo and ignored by Git. Persistent app configuration belongs in `app.json`; local release signing is applied by `scripts/android-signing.gradle`.

The native app build uses a workspace-specific cache under `C:\mcms-build` and CMake path shortening to avoid Windows/Ninja's 260-character path limit. This cache contains generated files, not source or signing credentials.

References: [Expo local builds](https://docs.expo.dev/guides/local-app-development/) and [Android app signing](https://developer.android.com/studio/publish/app-signing).
